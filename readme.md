# 🌟 IF Nexus - Vitrine de Projetos do IFRN

**IF Nexus** é a vitrine oficial de projetos dos estudantes do IFRN! Aqui, você pode **publicar, gerenciar e compartilhar seus trabalhos acadêmicos** de forma prática, organizada e bonita.

---

## 🏆 Funcionalidades Principais

✨ **Para todos os usuários:**

* Login seguro (suap + cadastro próprio)
* Visualização de perfis e projetos favoritos
* Curtidas e comentários nos projetos

🚀 **Para autores de projetos:**

* Criar, editar e excluir projetos com facilidade
* Upload de PDFs e imagens
* Adicionar autores, objetivos, metodologias e links
* Feedback a partir de comentários e curtidas de usuários

## ⚡ Instalação Rápida

```bash
# Clone o projeto
git clone https://github.com/marcoscassian/ifnexus
cd ifnexus

# Ambiente virtual
python -m venv env
source env/bin/activate  # Linux/Mac
env\Scripts\activate     # Windows

# Instale dependências
pip install -r requirements.txt

# Rodando localmente
py app.py
```

💻 **Acesse:** [http://127.0.0.1:5000](http://127.0.0.1:5000)

## 📂 Estrutura do Projeto

```
if-nexus/
│

├─ utils/             # Funções auxiliares
```
